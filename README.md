# موظف AI — الموقع التعريفي

صفحة هبوط عربية (RTL) لموظف الاستقبال الصوتي لعيادات الرياض.
موقع ثابت بملف واحد — بلا إطار عمل وبلا خطوة بناء تحتاج Node.

**الإنتاج:** <https://mowazafai.com>

---

## البنية

```
index.html                  ← الموقع المبني (هذا ما تخدمه Vercel)
mowazafai-landing.html      ← المصدر — عدّل هنا فقط
build.sh                    ← يبني index.html من المصدر
favicon.svg
vercel.json                 ← رؤوس الأمان والتخزين المؤقت
serve.ps1                   ← خادم محلي لويندوز (بلا Node)
supabase/
  schema.sql                ← جدول الليدات + سياسة RLS
  email-notify.sql          ← تنبيه الإيميل عبر pg_net + Resend
```

> **عدّل `mowazafai-landing.html` فقط.** ملف `index.html` يُولَّد آلياً،
> وأي تعديل مباشر عليه يضيع عند البناء التالي.

## التطوير المحلي

```bash
bash build.sh
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
```

ثم افتح <http://localhost:4173>. الخادم يرسل نفس رؤوس الأمان الموجودة
في `vercel.json` — بما فيها CSP — حتى تنكشف أي مشكلة محلياً لا في الإنتاج.

## النشر على Vercel

1. **Add New → Project** واختر هذا المستودع
2. **Framework Preset:** `Other`
3. **Root Directory:** اتركه فارغاً (الجذر)
4. **Build Command:** اتركه فارغاً
5. **Output Directory:** اتركه فارغاً
6. **Deploy**

Vercel يخدم `index.html` مباشرة. كل دفعة إلى `main` تُنشر تلقائياً.

## الإعداد

### Supabase (تخزين الليدات)

شغّل `supabase/schema.sql` في **SQL Editor**. الجدول مقفل بـRLS:
إدخال فقط من المتصفح، بلا قراءة ولا تعديل ولا حذف.

مفتاح `anon` في `mowazafai-landing.html` **علني بطبيعته** — أمانه من
RLS لا من إخفائه. لا تضع مفتاح `service_role` في الصفحة أبداً.

### تنبيه الإيميل

شغّل `supabase/email-notify.sql` بعد وضع مفتاح Resend فيه.

⚠️ **لا تحفظ المفتاح الحقيقي في Git.** الملف هنا يحوي عنصراً نائباً
(`RESEND_API_KEY_HERE`). ضع المفتاح عند اللصق في SQL Editor فقط.

المُرسِل الافتراضي `onboarding@resend.dev` مشترك بين مستخدمي Resend،
وGmail يصنّفه عشوائياً غالباً. وثّق نطاقك من **Resend → Domains**
وبدّل `v_from` ليصل البريد إلى الوارد مباشرة.

## نقاط في الكود تستحق الانتباه

- **المحتوى لا يختفي أبداً.** حالة الإخفاء لا تُطبَّق إلا بعد التأكد من
  تحميل GSAP. لو فشل الـCDN أو عُطّل الجافاسكربت، تظهر الصفحة كاملة.
- **حارس الظهور** يكشف أي عنصر بقي مخفياً داخل الشاشة خلال ٦٠٠ms.
- **النموذج لا يدّعي النجاح.** لا يقول «تم» إلا برد `2xx` من Supabase؛
  وعند الفشل يُبقي البيانات في الحقول ويعرض بديل واتساب.
- **توحيد الجوال:** تسع صيغ إدخال (عربية-هندية، فارسية، `05`، `+966`،
  `00966`) تُخزَّن كلها `+9665XXXXXXXX`.
- **الحركة:** GSAP + ScrollTrigger + Lenis، وكلها تُتجاوَز عند
  `prefers-reduced-motion`، والتثبيت وParallax مطفآن تحت 769px.
